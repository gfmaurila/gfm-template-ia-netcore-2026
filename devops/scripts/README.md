# Scripts operacionais futuros

Não há scripts nesta fase. Scripts futuros exigem objetivo/responsável, validação de parâmetros, modo seguro, registro de logs redigido, tratamento de erro, idempotência quando aplicável e documentação.

Não usar curingas ou nomes não resolvidos para limpeza. Operações destrutivas devem verificar ambiente e pedir confirmação explícita.
