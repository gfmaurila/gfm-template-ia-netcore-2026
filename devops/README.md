# DevOps futuro

Área para padrões documentais e, somente após autorização em fase futura, automações operacionais. Esta entrega contém apenas Markdown.

- `docker/`: padrões por tipo de host e testes.
- `compose/`: planejamento de ambientes locais descartáveis.
- `github-actions/`: desenho de CI/CD sem fluxos de trabalho YAML.
- `scripts/`: convenções futuras, sem scripts nesta fase.
- `environments/`: separação segura de configuração.
- `security/`: proteção de supply chain e pipeline.
