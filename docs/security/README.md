# Segurança

Documentar threat models, controles, revisões e risco residual em arquivos específicos. Aplicar `governance/security/security-baseline.md` a todo cenário.

Revisões não devem incluir segredos reais; referências a achados devem ser redigidas e apontar para evidência sanitizada.

[Linha de base Front-end](frontend-security.md) complementa o linha de base com controles para browser, formulários, APIs, dependências Web e Mobile.
