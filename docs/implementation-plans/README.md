# Planos de implementação

Criar plano somente após aprovação da SPEC e das decisões arquiteturais necessárias. Usar `templates/implementation-plans/implementation-plan-template.md`. O plano relaciona SPECs, módulos efetivamente selecionados, arquitetura/stack, fases e dependências, persistência, testes, Docker, GitHub Actions, riscos/mitigações, critérios de conclusão, implantação gradual/reversão (rollback) e tarefas.

Solicitar aprovação do plano e autorização explícita de escopo antes de iniciar implementação. Documentar dependências e riscos; o plano aprovado não autoriza automaticamente execução de tarefas ou implantação.

Para a Fase 00 Back-end, consultar o [PLAN-000-bootstrap](../../templates/implementation-plans/PLAN-000-bootstrap.md), adaptá-lo à SPEC aprovada e solicitar aprovação antes de iniciar as tarefas.
