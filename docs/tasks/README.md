# Tarefas

Usar [`task-template.md`](../../templates/tasks/task-template.md). Cada tarefa tem ID único, objetivo, escopo/exclusões, dependências reais, critérios de aceite, testes, riscos e evidências.

Decompor para que uma unidade possa ser revisada e validada. Dependências devem ser explícitas; status não muda para concluído sem Quality Gates aprovados.

Fase 00 Back-end: [modelos TASK-BE-000 a TASK-BE-014](../../templates/tasks/bootstrap/back-end/README.md). Front-end: [modelos FE-00-01 a FE-00-14](../../templates/tasks/bootstrap/front-end/README.md). São extensões opcionais do modelo geral; selecionar somente tarefas aplicáveis.
