# Operações

Incluir requisitos de execução, configuração por ambiente, integridade/prontidão (readiness), SLOs, alertas, implantação, reversão (rollback), backup/restauração e responsáveis. Todo passo destrutivo precisa de escopo e confirmação.

Runbooks ficam em `runbooks/`; material de banco e ciclo de esquema em `db/`.
