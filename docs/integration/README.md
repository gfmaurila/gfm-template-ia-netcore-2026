# Integrações

Documentar contratos, autenticação, timeouts, nova tentativa (retry), rate limits, dados tratados, classificação de segurança, idempotência, versionamento, observabilidade e runbooks.

Preferir OpenAPI/AsyncAPI ou esquemas apropriados quando escolhidos. Exemplos usam dados sintéticos e endpoints neutros; segredos e URLs internas nunca são incluídos.
