# Decisões arquiteturais

Armazene ADRs em arquivos Markdown nomeados `NNNN-titulo-curto.md`, com identificador estável, status, contexto, decisão, alternativas, consequências e data.

Use `templates/architecture-decisions/adr-template.md`. Uma decisão substituída deve apontar para a decisão sucessora; não apagar o histórico.
