# Mermaid

Use Mermaid para diagramas leves revisados em texto: sequência, dependências, fluxos de decisão e visão simplificada. O Draw.io continua sendo a ferramenta principal para diagramas editáveis.

Indique atores, limites de confiança e sistemas externos sem usar dados reais. O diagrama deve refletir uma especificação aprovada, não substituir a validação da implementação.
