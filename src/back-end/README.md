# Back-end

Área documental para APIs, Workers, Batch e demais hosts de back-end selecionados no projeto. A arquitetura .NET existente permanece descrita em `docs/architecture/` e `blueprints/`; esta expansão não a substitui nem a implementa.

Selecionar persistência, mensageria, autenticação e processos hospedados somente quando os requisitos aprovados justificarem. Usar testes descartáveis e políticas de segurança existentes. Não criar código nesta fase.

Para planejar a fundação antes da implementação, consultar os [modelos de Bootstrap Back-end](../../templates/tasks/bootstrap/back-end/README.md), a [SPEC-000](../../templates/specifications/SPEC-000-fundacao-tecnica.md) e o [PLAN-000](../../templates/implementation-plans/PLAN-000-bootstrap.md).
