# Código futuro

`src/` é reservado aos módulos de implementação selecionados para um projeto futuro. Os documentos desta árvore descrevem opções e limites; não são aplicações nem autorização para gerar código.

- `back-end/`: referência documental para serviços e APIs.
- `front-end/`: cenários Web, Mobile e compartilhados.

Criar somente os módulos solicitados e aprovados. Front-end e back-end podem ser independentes ou combinados conforme o blueprint; nenhum módulo opcional deve ser criado por padrão.
