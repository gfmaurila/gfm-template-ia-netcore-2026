# FE-00-07 — Definir autenticação e segurança

- **Objetivo:** planejar identidade, sessão, autorização e controles de segurança para a plataforma.
- **Dependências:** modelo de ameaças; contrato de identidade; FE-00-06 quando houver API.
- **Escopo:** selecionar fluxo de autenticação aprovado, permission UX, CSRF/CORS/CSP, armazenamento de sessão/token, registro de logs/privacidade. Não implementar autenticação.
- **Responsável/agente/status:** [preencher] / Pendente
- **Segurança:** aplicar `docs/security/frontend-security.md`; autorização no servidor; Mobile usa armazenamento seguro; nunca incluir segredos no cliente.
- **Validações/evidências:** revisão de segurança aprovada, casos negativos e dados minimizados documentados.
- **Aceite:** fluxos e responsabilidades cliente/servidor explícitos; riscos residuais aceitos por responsável; testes exigidos definidos.
