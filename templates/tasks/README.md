# Modelo de tarefa

Use um ID globalmente único dentro da iniciativa. Uma tarefa precisa ser verificável e executar apenas escopo aprovado.

Modelos Bootstrap são extensões do template geral, sem substituí-lo: [Back-end](bootstrap/back-end/README.md) e [Front-end](bootstrap/front-end/README.md). Selecionar somente tarefas aplicáveis e não executar esses modelos nesta fase.
