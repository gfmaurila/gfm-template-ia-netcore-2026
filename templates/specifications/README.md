# Modelos de especificação

Use `specification-template.md` para requisitos funcionais, técnicos e não funcionais. Manter hipóteses, decisões pendentes e exclusões explícitas.

Para a fundação técnica, use a extensão [SPEC-000](SPEC-000-fundacao-tecnica.md) junto ao modelo geral. Ela é um modelo, não uma SPEC aprovada de projeto real.
