# Modelos documentais

Copie o modelo necessário para a documentação da iniciativa e preencha todos os campos aplicáveis. Remova campos realmente não aplicáveis com justificativa; não deixe placeholders como se fossem decisões.

- `specifications/`: requisitos e especificações.
- [SPEC de fundação técnica](specifications/SPEC-000-fundacao-tecnica.md): extensão reutilizável do modelo geral para seleção inicial de stack/requisitos.
- `implementation-plans/`: planejamento aprovado.
- [PLAN de Bootstrap Back-end](implementation-plans/PLAN-000-bootstrap.md): sequência e dependências das tarefas de fundação.
- `tasks/`: tarefas individuais.
- [Bootstrap Front-end](tasks/bootstrap/front-end/README.md): modelos de tarefas Fase 00; não substituem o modelo geral nem os materiais de back-end.
- [Bootstrap Back-end](tasks/bootstrap/back-end/README.md): modelos BE-000 a BE-014; usar apenas tarefas aplicáveis.
- `architecture-decisions/`: ADRs.
- `security-reviews/`: revisão de segurança.
- `test-plans/`: plano e relatório de testes.

Todos os modelos são Markdown e não executam ações.
